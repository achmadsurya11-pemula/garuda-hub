# Garuda-Hub (Laravel MVC)

Aplikasi web lelang proyek berbasis Laravel yang dimigrasi dari PHP Native. Proyek ini dibuat untuk memenuhi tugas mata kuliah.

## Fitur Utama
- **Autentikasi & Role**: Pengguna dapat masuk/daftar dengan peran sebagai Klien, Developer, atau Admin.
- **Manajemen Proyek**: Klien dapat memasang proyek lelang baru dan memilih pemenang penawaran.
- **Sistem Bidding**: Developer dapat mengajukan penawaran harga, durasi, dan proposal proyek.
- **Panel Admin**: Mengelola daftar pengguna (mengubah peran/menghapus akun) dan proyek.

## Prasyarat
- PHP >= 8.2
- Composer
- MySQL / Laragon
